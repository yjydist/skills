# swiss-grid-design 使用文档

`swiss-grid-design` 用于将内容组织为瑞士国际主义方向的视觉方案, 也可以调整或评审现有作品. 默认使用方角, 中性色, 一个可选强调色, 清晰字体层级和基于网格的非对称布局, 覆盖网页, App, Dashboard, 海报, 幻灯片和文档.

## 使用方式

+ 将 [skill 入口](../skills/swiss-grid-design/SKILL.md) 连同 `references/` 一起提供给支持 skill 的工具, 保留相对路径.
+ 在请求中说明要创建, 调整还是评审, 并提供核心内容和交付形式. 有品牌规范, 现有模板或设计系统时一并提供, 它们优先于默认值.
+ 数字界面可提供目标视口或设备, 静态作品可提供画幅, 阅读距离和输出用途. 只有缺失信息会实质改变结果时才需要补充, 普通视觉选择由 skill 采用默认值.
+ 本 skill 提供设计指导, 不自带字体, 图像素材或制作工具. 最终输出依据当前工具能力和用户要求, 可能是实际作品, 代码实现, 设计说明或评审意见.

下方示例使用 `$swiss-grid-design` 表示调用. 工具不支持这种形式时, 可以指定 `skills/swiss-grid-design/SKILL.md` 的实际路径.

## 调用示例

### 中文移动页面

```text
使用 $swiss-grid-design 为以下内容设计中文移动端活动页面.
目标是让用户了解活动并报名, 首先输出布局方案和关键设计变量.
目标视口宽度为 390px, 同时考虑 320px 的窄屏.
内容: [活动标题, 简介, 日期, 地点, 报名方式]
```

预期结果是标题, 活动信息和报名操作的清晰层级, 4 列对齐基准及跨满列的主要模块. 默认方角和中性色, 不为保住列数缩小正文; 同时说明长标题换行和窄屏调整方式.

### 带品牌色和多系列图表的 Dashboard

```text
使用 $swiss-grid-design 调整现有 Dashboard 的视觉层级.
保留品牌蓝色 #0057B8, 数据和既有图表类别编码.
图表包含五个系列, 同时存在成功, 警告和错误状态.
优先复用现有组件, 输出调整方案和必要的配色例外.
```

预期结果是用品牌蓝替换默认红色强调色, 以文字层级和对齐组织指标. 多系列保留既有语义编码, 配合标签, 线型或符号区分; 状态提供文字或图标线索. 不把所有系列强制改为灰色, 不把品牌色同时当作无说明的错误色.

### 研究汇报幻灯片

```text
使用 $swiss-grid-design 将以下材料设计为 16:9 研究汇报幻灯片.
保留所有实验数据和图表含义, 每页突出一条主要信息.
使用现有模板, 必要时拆页, 不通过缩小关键文字塞满内容.
材料和模板: [提供实际内容及模板]
```

预期结果是遵循模板画幅与规范的网格版式, 使用适合观看距离的字号, 各页形成自己的主焦点. 并列图表保持可比较的尺度与编码, 不套用网页像素参数.

### 评审现有作品

```text
使用 $swiss-grid-design 评审这个页面的网格, 层级, 间距和配色.
列出能具体定位的问题及建议, 本次只评审.
```

预期结果是具体到元素或区域的改进建议, 区分风格偏离与影响辨识或操作的问题. 静态图无法证明键盘操作, 缩放重排或完整可访问性, 这些检查会标为未验证.

## 默认行为与例外

+ 默认是设计起点, 不是对品牌, 模板和内容的覆盖指令. 用户要求其他风格时不会强行套用.
+ 网格约束主要容器和共同对齐线, 允许光学校正; 非对称不妨碍对比表格和重复模块采用等宽布局.
+ 基础配色限制作用于界面和版式, 不强制改动原始照片, 标识和数据编码. 必要功能色可以保留, 同时提供非颜色线索.
+ 方角适用于常规容器和控件, 圆形语义元素及品牌要求可以例外. 只调整冲突部分, 并解释影响整体风格的例外.
+ Web 默认间距和网格按可用宽度适配. 原生 App 使用平台单位, 静态作品根据成品尺寸和阅读距离选择参数.
+ 不按固定比例删除视觉元素, 不擅自删掉必要内容. 对比度与交互检查仅说明已验证项目, 不据此宣称完整 WCAG 合规.
