# mentor-profile 使用文档

`mentor-profile` 汇总导师对图形交付物的主观偏好, 当前覆盖画图要求: 图标, 配色和板块处理方式. 在绘制或调整面向导师的图形时, 让执行工具直接按这些要求产出, 减少返工.

## 使用前提

+ 将 [skill 入口](../skills/mentor-profile/SKILL.md) 提供给支持 skill 的工具, 保留相对路径.
+ 在请求中说明图形面向导师, 并给出要画的内容和交付形式. 有模板, 现有素材或历史图时一并提供, 它们与画像冲突时优先.
+ 画像当前只覆盖画图. 需要补充其他领域时, 在 SKILL.md 中新增对应小节, 保持同一结构.

下方示例使用 `$mentor-profile` 表示调用该 skill. 工具不支持这种形式时, 可以指定 `skills/mentor-profile/SKILL.md` 的实际路径.

## 调用示例

### 为导师绘制方法示意图

```text
使用 $mentor-profile 为论文的方法部分绘制一张横向示意图, 这张图要给老师看.
展示数据预处理, 模型训练和模型评估三个板块, 以及各板块内的关键步骤.
```

预期结果是实心填充的图标; 颜色控制在 2-3 种, 只取自黑白与红, 橙, 黄, 绿, 蓝; 每个板块的图形与文字保持同色; 板块之间用线条划分, 背景保持白色不填充.

### 按画像调整已有图

```text
使用 $mentor-profile 按导师的偏好检查并调整这张图, 保留原有内容和布局.
[提供现有图或源文件]
```

预期结果是先逐项对照画像指出差距 (线性图标, 颜色数量, 板块配色, 背景填充), 再按差距调整; 因工具限制无法满足的项目会说明, 不静默跳过.

## 默认行为与例外

+ 画像只约束形式与呈现, 不改变内容, 数据和结论.
+ 用户明确要求与画像冲突时按用户要求执行, 并说明偏离; 面向其他受众的图形不默认套用画像.
+ 画像未覆盖的领域按常规做法处理, 不推测导师在其他方面的偏好.
