# 导师画像

汇总导师对交付物的个人偏好, 当前只覆盖画图, 供 agent 在产出面向导师的图形时直接遵循, 减少因风格不符造成的返工.

## 前提条件

+ 运行时: 无. 检查: `true`; 以状态 0 退出表示本项没有需要检测的运行时.
+ 第三方依赖: 无. 检查: `true`; 以状态 0 退出表示本项没有需要安装或导入的包.
+ 外部程序与认证: 无. 检查: `true`; 以状态 0 退出表示本项没有需要检测的外部程序或认证. 本 skill 只约束绘图风格, 读取图片和产图的能力由执行工具提供, 不要求特定程序.
+ 检查命令按 POSIX shell (sh/bash) 编写. 以 `true` 作为检查命令的条目表示该项无要求, 在不支持 `true` 的 shell 中直接视为通过.

## 适用与优先级

+ 在用户说明产出面向导师 (如 "这张图给老师看"), 或明确调用本 skill 时适用. 其他绘图任务按常规方式处理, 不默认套用画像.
+ 用户的明确要求及提供的模板和素材优先. 与画像冲突时按用户要求执行, 并说明偏离画像的地方.
+ 画像未覆盖的领域按常规做法处理, 不推测导师在其他方面的偏好.
+ 当前工具无法满足某条要求时, 说明限制, 不静默忽略.

## 画图要求

### 图标

+ 图标使用实心填充 (fill) 的样式, 不使用单薄线条勾勒出来的线性图标.

### 配色

+ 除黑色和白色外, 颜色最多 5 种, 只使用红, 橙, 黄, 绿, 蓝; 不引入灰色等其他颜色.
+ 通常使用 2-3 种颜色, 也可以用 4 种; 5 种是上限, 基本不出现.
+ 同一色系的深浅变化 (如深蓝与浅蓝) 按一种颜色计数.

### 板块

+ 同一板块的颜色保持统一, 包括其中的文字; 优先只使用一种颜色.
+ 一个板块最多使用两种颜色, 且必须有一种明显占据主导, 避免两种颜色比例相当.
+ 颜色以板块为单位统一, 不用颜色区分板块内的元素或传递含义, 避免单个板块颜色杂乱.
+ 板块之间用线条划分; 不填充板块背景色, 保持默认的白色背景.
