# 周报与月报

使用 [周报模板](references/weekly-template.typ) 或 [月报模板](references/monthly-template.typ) 和 [渲染脚本](scripts/render.py) 生成周报或月报, 脚本按报告类型选择模板. 保留模板中的 A4 页面, 字体, 字号, 页边距, 标题, 信息行和类别表格, 内容过长时自然分页.

## 工作流程

### 1. 收集内容

+ 类型: 周报或月报.
+ 年份和月份: 整数. 未提供时使用用户当前日期, 并在交付时说明. 语境存在歧义时先确认.
+ 第几次: 仅周报需要, 表示当月第几次周报, 正整数. 月报没有此字段.
+ 姓名和学号.
+ 日期范围: 起止日期, 如 2026.3.2 至 2026.3.8. 周报通常为一周, 月报通常为整月.
+ 实验室、项目贡献条目和科研进展条目: 用户提供的非空条目列表, 保留原文, 顺序和条目内换行, 不增删或改写.
+ 其他: 实验室其他服务性工作, 运动情况, 心得体会, 反思教训四项内容, 没有时填 无.
+ 考勤: 平均打卡时长(小时)和上午 9:30 前打卡次数.
+ 自我评价: 非常满意, 满意或不太满意三选一.

仅类型, 月份, 各类内容或考勤等缺失时, 使用当前环境的询问工具或直接追问. 不因为年份缺失重复询问. 将明确的年份和月份一并传给脚本, 避免执行机器与用户日期不同.

### 2. 运行渲染脚本

需要 Python 3.9+ 和 Typst 0.13+. 模板优先使用 `Alimama FangYuanTi VF`, 其次 `Alimama FangYuanTi`; 两者都不存在时脚本回退到默认字体, 不停止渲染, 并通过结果中的 `font_note` 返回提示. 脚本会实际检查 Typst 版本和字体列表.

输入 JSON 包含以下字段. `nth` 仅周报需要. `attendance_hours` 与 `attendance_early` 可写数字或非空字符串. 其余文本字段均为非空字符串, `contributions` 与 `research` 为非空字符串数组. 使用 JSON 序列化工具保存内容, 不手工拼接用户文本到 shell 命令或 Typst 标记中.

```json
{
  "kind": "周报",
  "year": 2026,
  "month": 3,
  "nth": 2,
  "name": "常瑞",
  "student_id": "25031212280",
  "start": "2026.3.2",
  "end": "2026.3.8",
  "contributions": ["查看和对比实验室主机的硬件设备"],
  "research": ["读师兄师姐的大论文，积累综述的素材"],
  "service": "无",
  "exercise": "日常锻炼",
  "reflection": "无",
  "lesson": "无",
  "attendance_hours": 5.5,
  "attendance_early": 5,
  "self_evaluation": "满意"
}
```

把输入保存到临时 JSON 文件, 使用本 skill 中脚本的实际路径运行:

```bash
python3 /path/to/weekly-report/scripts/render.py --input /path/to/input.json --output-dir /path/to/output
```

+ 输出目录默认当前目录. 脚本将输入转为经过转义的 Typst 字符串, 不执行条目中的代码或标记.
+ 先在临时目录编译全部页面并检查尺寸, 成功后交付. 编译失败时显示错误, 不留下部分报告产物, 不静默改用其他方案.
+ 已有相同报告的源文件或图片时报告冲突, 不覆盖. 告知用户现有路径, 使用用户指定的新目录或由用户先处理原文件.

### 3. 核对并交付

+ 周报单页保留 `weekly-report-2026年3月第2次.png` 命名, 月报为 `monthly-report-2026年3月.png`. 多页使用 `...-第1页.png`, `...-第2页.png` 等连续页码.
+ 两种情况都输出同名 `.typ`. 源文件包含模板和完整数据, 可独立编译, 不依赖临时 JSON 或 skill 安装路径.
+ 每页为 A4 尺寸 300 DPI PNG, 即 2480 x 3508 像素. 不通过缩字, 截断或改写条目控制页数.
+ 使用当前环境的图像查看工具检查所有页面, 确认标题, 信息行, 表格边框, 中文字形, 各类别内容及分页没有丢失内容.
+ 汇报页数, 所有 PNG 路径和 Typst 源文件路径, 以及实际使用的默认年月. 最终产物只包含 `.png` 和 `.typ`, 临时输入不作为交付物.
+ 结果中的 `font_note` 非空时, 在交付说明里告知用户已回退字体, 中文字形可能与预期不同.

需要重新编译已交付源文件时, 多页 PNG 的输出路径必须包含 `{p}`:

```bash
typst compile "weekly-report-2026年3月第2次.typ" "weekly-report-2026年3月第2次-第{p}页.png" --format png --ppi 300
```

## 操作边界

+ 报告事实和内容一律来自用户, 不虚构, 补写或润色.
+ 用户未要求时不修改模板版式, 表格结构, 字体或页面尺寸.
+ 编译失败时报告完整错误及原因, 不把失败或部分产物报告为成功.
