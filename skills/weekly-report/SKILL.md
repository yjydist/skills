# 学期周报

使用 [模板](template.typ) 和 [渲染脚本](scripts/render.py) 生成周报. 保留模板中的 A4 页面, 字体, 字号, 页边距, 标题, 分割线和进展列表, 内容过长时自然分页.

## 工作流程

### 1. 收集内容

+ 年份: 未提供时使用用户当前年份, 并在交付时说明. 语境存在歧义时先确认.
+ 学期: 春季或秋季.
+ 周次: 正整数.
+ 进展条目: 用户提供的非空条目列表, 保留原文, 顺序和条目内换行, 不增删或改写.

仅学期, 周次或进展条目缺失时, 使用当前环境的询问工具或直接追问. 不因为年份缺失重复询问. 将明确的年份一并传给脚本, 避免执行机器与用户日期不同.

### 2. 运行渲染脚本

需要 Python 3.9+, Typst 0.13+ 和字体族 `Alimama FangYuanTi`. 脚本会实际检查 Typst 版本和字体列表. 缺失时报告并停止, 不自动安装或替换字体.

输入 JSON 只包含以下四个字段. 年份为 1 至 9999 的整数, 周次为正整数, 学期为 `春季` 或 `秋季`, `items` 为非空字符串数组. 使用 JSON 序列化工具保存内容, 不手工拼接用户文本到 shell 命令或 Typst 标记中.

```json
{
  "year": 2026,
  "semester": "春季",
  "week": 3,
  "items": ["修复 #issue 并验证 $HOME", "完成接口文档初稿"]
}
```

把输入保存到临时 JSON 文件, 使用本 skill 中脚本的实际路径运行:

```bash
python3 /path/to/weekly-report/scripts/render.py --input /path/to/input.json --output-dir /path/to/output
```

+ 输出目录默认当前目录. 脚本将输入转为经过转义的 Typst 字符串, 不执行条目中的代码或标记.
+ 先在临时目录编译全部页面并检查尺寸, 成功后交付. 编译失败时显示错误, 不留下部分周报产物, 不静默改用其他方案.
+ 已有相同学期和周次的源文件或图片时报告冲突, 不覆盖. 告知用户现有路径, 使用用户指定的新目录或由用户先处理原文件.

### 3. 核对并交付

+ 单页保留 `weekly-report-2026春-第3周.png` 命名. 多页使用 `weekly-report-2026春-第3周-第1页.png`, `...-第2页.png` 等连续页码.
+ 两种情况都输出 `weekly-report-2026春-第3周.typ`. 源文件包含模板和完整数据, 可独立编译, 不依赖临时 JSON 或 skill 安装路径.
+ 每页为 A4 尺寸 300 DPI PNG, 即 2480 x 3508 像素. 不通过缩字, 截断或改写条目控制页数.
+ 使用当前环境的图像查看工具检查所有页面, 确认标题, 分割线, 中文字形, 条目顺序及分页没有丢失内容.
+ 汇报页数, 所有 PNG 路径和 Typst 源文件路径, 以及实际使用的默认年份. 最终产物只包含 `.png` 和 `.typ`, 临时输入不作为交付物.

需要重新编译已交付源文件时, 多页 PNG 的输出路径必须包含 `{p}`:

```bash
typst compile "weekly-report-2026春-第3周.typ" "weekly-report-2026春-第3周-第{p}页.png" --format png --ppi 300
```

## 操作边界

+ 周报事实和条目一律来自用户, 不虚构, 补写或润色.
+ 用户未要求时不修改模板版式, 字体或页面尺寸. 分割线保持 `#line(length: 100%, stroke: 1pt)`.
+ 编译失败时报告完整错误及原因, 不把失败或部分产物报告为成功.
