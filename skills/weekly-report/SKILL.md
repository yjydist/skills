# 学期周报

将用户提供的学期, 周次和本周进展条目填入 Typst 模板, 渲染为一张 PNG 周报图片和对应的 Typst 源文件. 版式固定为标题, 分割线和一个进展列表.

## 核心原则

+ 周报内容一律来自用户输入, 不代替用户归纳, 补写或编造进展; 缺失的信息先询问, 不猜测.
+ 一次调用产出一个 PNG 周报图片和一个配套的 Typst 源文件, 文件名同前缀, 输出文件名包含学期和周次.
+ 不修改 [模板](template.typ) 的版式, 字体和页面尺寸, 只替换标题行中的年份, 学期, 周次和进展条目.

## 工作流程

### 1. 确认环境

运行以下命令, 两者都通过才继续:

```bash
which typst
typst fonts | grep -i alimama
```

+ 第一条应输出 typst 的安装路径(如 /opt/homebrew/bin/typst), 需要 typst 0.13 或更高版本.
+ 第二条应输出字体族名 `Alimama FangYuanTi`.
+ 任一命令失败或输出为空时, 向用户报告缺失项(typst 或 Alimama FangYuanTi VF 字体)并停止, 不尝试安装或替换字体.

### 2. 收集内容

从用户消息中提取四类信息:

+ 年份: 未提供时默认使用当前年份, 并在交付时说明该默认值; 用户语境存在歧义时先确认.
+ 学期: 春季或秋季.
+ 周次: 学期中的第几周.
+ 进展条目: 本周进展, 逐条使用, 不增删改写.

任一项缺失时, 用 AskUserQuestion 或直接追问补齐后再继续.

### 3. 填充模板并渲染

将本 skill 目录下的 template.typ 复制到用户工作目录, 命名为 `weekly-report-<年份><学期>-第<周次>周.typ` (与 PNG 同名, 扩展名不同), 把标题行中的年份, 学期和周次替换为用户内容, 并把列表条目替换为用户的进展条目, 每条一行, 格式为 `- 条目`. 模板中的示例内容仅用于试渲染, 交付前必须全部替换.

注意: 修改模板内容时, 分割线必须保持 Typst 的 `#line(length: 100%, stroke: 1pt)` 语法. 省略 `length` 在 typst 0.15 下只画出约 30pt 的短线, 而非横贯全宽; 也不要用 markdown 的 `---` 代替分割线.

然后运行(文件名按实际内容生成):

```bash
typst compile "weekly-report-2026春-第3周.typ" \
  "weekly-report-2026春-第3周.png" \
  --format png --ppi 144
```

+ 输出文件名形如 `weekly-report-<年份><学期>-第<周次>周.png` 和同名 `.typ` 源文件, 例如 `weekly-report-2026春-第3周.png` 与 `weekly-report-2026春-第3周.typ`.
+ 两个文件都输出到用户当前工作目录; `--ppi 144` 使图片宽度约为 1280px, 保证清晰度.

### 4. 交付前检查

+ 用 Read 查看生成的 PNG, 确认标题, 分割线和列表渲染正常, 中文字形正常而非 fallback 方块.
+ 确认 `.typ` 源文件与 PNG 同时存在于用户工作目录, 且文件名前缀一致.
+ 确认文件名与用户提供的学期和周次一致.
+ 向用户报告输出路径和图片尺寸, 同时报告 Typst 源文件路径.

## 操作边界

+ 不虚构, 补写或润色进展条目, 用户提供的条目原样呈现.
+ 用户未要求时不修改模板版式, 字体和页面尺寸.
+ typst 编译失败时, 展示完整错误输出并说明原因, 不静默重试或改用其他渲染方案.
