# 选择性深读报告模板

仅用于 paper-third-pass 的选择性模式. 报告正文使用简体中文, 保留必要的论文术语. 标题使用 `# 选择性深读报告`, 注明论文标题和实际读取的来源, 按以下四部分输出.

## 1. 阅读范围

+ 列出本次要回答的具体问题, 说明来自用户指定还是第二遍建议.
+ 列出实际检查的章节, 公式, 图表及代码范围. 代码未提供, 无法访问或未检查时分别如实说明.
+ 明确未检查的范围. 只读取解决问题所需的部分及必要上下文, 不声称完成全篇审计.

## 2. 逐问题分析

每个问题单独分析, 包含以下内容:

+ 问题及结论: 直接回应问题, 无法确定时说明目前能确定到什么程度.
+ 推理: 展示必要的公式推导, 实验对比或代码路径, 解释判断如何形成.
+ 证据: 给出实际读取的论文或代码定位; 关键前序结论必须回原文验证.
+ 限制: 说明缺失信息, 尚未控制的变量或其他可能解释, 不把未报告的信息补成事实.

区分作者声称, 论文证据, 自己的推断和推测. 问题之间共享证据时可以交叉引用, 不重复完整摘要. 只有与问题直接相关时才给出复现步骤或研究延伸.

## 3. 未解决问题

列出本轮仍无法回答的部分及原因, 给出能解决该缺口的具体下一步. 无缺口时如实说明. 新发现的问题超出当前范围时记录下来, 不自动扩展为全篇深读.

## 4. 证据索引

将关键结论对应到 Section, Page, Figure, Table, Equation, Appendix 或代码文件位置. 定位来自本次实际读取的材料, 无法定位时明确说明, 不伪造编号或行号.
