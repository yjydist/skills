# 瑞士网格设计

用网格, 字体, 对齐和留白组织信息, 形成清晰, 理性, 克制的视觉系统. 不通过机械加入红色方块, Helvetica 或可见网格线来模拟历史海报.

## 适用与优先级

+ 本 skill 指导视觉设计, 不替代任务所需的制作工具或交付格式. 根据用户要求输出作品, 实现, 设计方案或评审意见, 不默认只生成提示词.
+ 先遵循用户的明确要求及其提供的品牌规范, 模板和现有设计系统. 修改现有作品时保留任务范围以外的内容和结构. 用户指定其他风格时, 不强行套用本风格.
+ 下述视觉规则都是默认值. 品牌规范, 可读性, 交互语义, 数据辨识或媒介限制与默认值冲突时, 只调整必要部分. 对改变配色, 几何或布局等主要特征的例外, 在交付说明中简述原因.

## 核心规则

### 信息与网格

+ 先识别内容层级和阅读顺序, 再选择版式. 每个页面, 画面或主要内容区域应有可辨识的主焦点; 多页作品和长页面可以在不同区域形成各自的焦点, 无须共享唯一焦点.
+ 让主要容器的起止边界和同层级内容共享对齐线. 内容可以跨列, 留白也可以占据整列. 不要求每个字形边缘都机械贴合网格, 允许文字, 图标和图形做小幅光学校正.
+ 默认左对齐, 用大标题与小信息, 大图与留白等关系形成非对称平衡. 对比表格, 重复指标和并列选项可以等宽或对称, 不为追求非对称而破坏可比性和阅读顺序.
+ 先用中性色确认层级, 再加入强调色. 非对称, 红色和大留白都必须服务于内容, 不为了风格而额外添加.

### 字体与间距

+ 默认使用一套无衬线字体体系, 主要字重为 400, 500, 700. 中西文回退字体可以组成同一体系, 不算作额外装饰字体. 等宽字体限于代码, 数字标识等确有需要的内容.
+ 以字号, 字重, 位置和间距建立明显层级. 每个页面通常使用不超过 5 个主要文字层级, 长文档按语义需要增加. 字号差异应对应不同角色, 不堆叠难以辨别的近似层级.
+ 同类组件共享间距值, 组间距离应大于组内距离. 数字界面以 8px 为间距基准, 4px 用于微调; 这不要求字高, 行高, 线宽和光学校正都为 8px 的倍数.
+ 留白用于分组和突出重点. 内容拥挤时先调整分组, 布局和冗余信息, 不直接把所有文字缩小或删除必要内容.

### 几何与组件

+ 容器, 卡片, 按钮, 输入框和图片裁切默认方角, 即 `border-radius: 0`. 圆形可用于头像, 单选按钮, 状态点和具有圆形语义的图形. 小圆角, 胶囊或其他形状仅在品牌或控件识别确有需要时采用, 不作为默认装饰.
+ 优先用留白, 字体层级, 分隔线和背景明度分区. 内容是独立对象, 整块可交互或需要明确边界时才使用卡片; 嵌套容器只有在表达真实层级时保留.
+ 边框默认细线, 页面默认无阴影. 下拉菜单, 弹出层和对话框需要表达遮挡或层级时, 可以采用克制的中性阴影. 避免无信息作用的渐变, 发光, 毛玻璃和悬浮装饰.
+ 主按钮使用高对比实色, 次按钮使用清晰边界或文本层级. 输入框保留标签, 可辨识边界和焦点指示; 不通过取消焦点样式获得简洁外观.

### 配色与素材

+ 界面和版式的基础配色默认黑, 白, 灰, 加一个红色强调色. 红色可以不用, 品牌色可以替换红色. 强调色用于当前重点或主要操作, 不大面积填充所有模块.
+ 原始照片, 品牌标识和已有数据编码不受基础调色板强制限制. 不为统一风格擅自改色, 裁掉信息或改动图表中的数值和类别含义.
+ 错误, 警告, 成功和数据类别可以采用必要的功能色. 同时提供文字, 符号, 线型或其他非颜色线索, 保持同一语义的编码一致. 不让强调色和错误色仅靠颜色表达不同含义.
+ 图标用于识别和操作, 统一线宽与几何风格. 图片优先矩形, 与容器对齐; 裁切不得损失主题信息. 不为了填空而加入无关图标, 素材图或抽象背景.

### 数据与动效

+ 表格的标签列左对齐, 数值列右对齐, 可用时使用等宽数字. 指标通过字号, 位置和分隔线分层, 不默认全部包装成大卡片.
+ 图表优先中性色, 一个重点系列使用强调色, 标签能直接对应数据时优先直接标注. 多系列难以区分时, 先使用线型, 符号或分面; 仍影响辨识时允许有限的功能色及必要图例. 保留原始数据与既定编码.
+ 动效只用于反馈, 状态切换和帮助理解空间关系. 采用短促的透明度或位移过渡, 尊重减少动态效果的系统偏好; 避免持续漂浮, 装饰性视差和反复闪烁.

## 执行流程

1. 确认媒介, 用户目标, 核心内容和必须遵循的现有规范. 保留原文的语言, 事实和数据. 只有缺失信息会实质改变结果时才询问, 常规视觉选择直接采用默认值.
2. 建立阅读顺序和主焦点, 选择网格与文字角色. 没有既定参数或需要跨媒介适配时, 读取 [设计参考](references/design-guide.md) 中的相关章节; 生成下游提示词时读取其中的模板.
3. 完成中性色结构, 再加入必要强调色, 素材, 状态和交互. 实现时复用既有组件和设计变量, 不因应用本 skill 重写无关部分.
4. 按实际输出条件检查结果. 数字界面检查窄屏, 长文本, 键盘焦点和缩放; 静态作品按成品尺寸和观看距离检查. 只有设计说明或图像预览时, 明确区分已观察的问题与未验证的运行行为.
5. 删除不承载信息, 识别或交互作用的元素, 不按固定比例删减. 修正问题后按用户要求交付, 简述影响整体风格的例外和实际验证结果.

## 交付前检查

+ 主焦点和阅读顺序是否清楚, 主要容器是否共享对齐线?
+ 字体与间距是否一致, 留白是否表达分组而非挤占必要内容?
+ 方角和中性色是否仍是默认特征, 例外是否有具体功能依据?
+ 图片与数据是否保留原意, 状态与系列是否能通过非颜色线索辨识?
+ 数字界面是否满足 [设计参考](references/design-guide.md#数字界面的可读性与交互检查) 中适用的检查项, 静态作品是否在目标输出条件下可读?
+ 装饰是否具有明确作用, 汇报是否只包含实际完成的验证?
