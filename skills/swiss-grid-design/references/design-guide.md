# 设计参考

本文件提供无既定设计规范时的起始参数, 媒介适配和提示词模板. 数值是本 skill 的设计默认值, 不是瑞士国际主义的通用标准. 按当前任务读取相关章节, 有现成规范时优先复用.

## 基础设计变量

### 颜色与边界

| 角色 | 默认值 | 用途 |
| --- | --- | --- |
| 主要文字 | `#111111` | 标题, 正文和核心数值 |
| 次要文字 | `#595959` | 辅助说明和次要信息 |
| 主背景 | `#FFFFFF` | 页面和内容区域 |
| 次背景 | `#F5F5F2` | 轻量分区和低强调背景 |
| 分隔线 | `#D9D9D6` | 非必要识别边界的结构分隔 |
| 控件边界 | `#595959` | 需要靠边界识别的输入框等控件 |
| 强调色 | `#E10600` | 当前重点或主要操作, 可被品牌色替换 |
| 圆角 | `0` | 容器, 卡片, 按钮, 输入框和图片 |
| 细线 | `1px` | 数字界面的默认边框与分隔线 |
| 强分隔线 | `2px` | 少量使用的主要区域分隔 |
| 阴影 | 无 | 浮层需要时局部添加中性阴影 |

+ 颜色按角色复用, 不逐组件任意挑选. 状态色和多系列图表颜色由实际语义决定, 不自动增加整套高饱和配色.
+ 浅灰分隔线不适合直接作为控件的唯一识别边界. 背景, 字重, 字号或品牌色变化后, 重新检查实际前景与背景组合.
+ 深色界面重新映射文字, 背景和边界角色, 保持层级和对比度; 不直接反转全部颜色.

### 间距与字体

+ 数字界面的间距序列为 `4, 8, 16, 24, 32, 48, 64, 96, 128px`. 4px 用于图标与文字等微小间距; 控件内边距通常从 8px 或 16px 起, 模块间距从 24px 或 32px 起, 主要区域间距从 48px 或 64px 起.
+ 这是一套间距序列, 不是要求所有尺寸都使用这些数值. 先复用已有变量; 必须增加新值时, 让同类场景共享它.
+ 拉丁文字默认选用可用的 Inter, Helvetica Neue 或 Arial. 简体中文搭配可用的 Noto Sans SC, Source Han Sans SC, PingFang SC 或系统无衬线字体. 优先保证字符覆盖和输出环境可用, 不假定字体已安装或获准嵌入.
+ 主要字重为 400, 500, 700. 中文正文避免额外增加字距; 需要调整行长时先调整容器宽度和排版, 不拉伸字形.

## 数字界面参数

### 响应式网格

以下宽度指当前布局区域的可用宽度. 全页布局通常对应视口宽度; 有侧栏或嵌入面板时, 使用主内容区域的宽度判断.

| 布局区域宽度 | 列数 | 列间距 | 左右外边距 |
| --- | --- | --- | --- |
| 小于 768px | 4 | 16px | 16px |
| 768px 至小于 1024px | 8 | 24px | 32px |
| 1024px 及以上 | 12 | 24px | 48px |

+ 主内容最大宽度默认 1280px, 剩余横向空间作为外侧留白. 数据工作台需要更多空间时可放宽, 长文正文应单独限制行长.
+ 列数描述对齐基准, 不表示必须并排放置同等数量的内容. 窄屏内容默认跨满 4 列, 次要模块按阅读顺序堆叠.
+ 断点是起点. 内容在断点前已出现拥挤或溢出时, 提前切换布局, 不缩小正文来保住列数. 放大后按实际可用宽度重新排布.
+ 固定顶部导航, 侧栏和浮层要检查其占用空间. 不让视觉布局顺序与键盘或辅助技术的阅读顺序冲突.

### 文字角色

默认根字号按浏览器设置继承. 下表的 px 数值按 16px 根字号换算, 实现时优先使用 rem 和无单位行高.

| 角色 | 宽布局字号 | 窄布局字号 | 默认行高 |
| --- | --- | --- | --- |
| 展示标题 | 4rem / 64px | 2.5rem / 40px | 1.1, 中文可放宽至 1.2 |
| 页面标题 | 2.5rem / 40px | 2rem / 32px | 1.2 |
| 区域标题 | 1.75rem / 28px | 1.5rem / 24px | 1.3 |
| 正文 | 1rem / 16px | 1rem / 16px | 1.5, 长中文段落可用 1.6 |
| 辅助信息 | 0.875rem / 14px | 0.875rem / 14px | 1.5 |

+ 展示标题用于首屏或短标题, 无此内容时省略该角色. 不要求每页用满五级字号.
+ 重要说明和操作标签不降为难读的小字. 长标题允许换行, 检查中文, 中西文混排和连续标识的溢出, 不使用固定高度裁切必要文字.
+ 长文每行长度以阅读舒适为依据, 可从中文约 30 至 40 个字, 拉丁文字约 60 至 75 个字符开始调整. 不为贴合网格强行两端对齐或插入空格.

### 数字界面的可读性与交互检查

以下只列出与本视觉规则直接相关的检查, 不构成完整的 WCAG 审核. Web 检查依据 [WCAG 2.2](https://www.w3.org/TR/WCAG22/); 原生 App 同时遵循其平台规范, 不将 CSS 像素参数直接视作原生单位.

+ 普通阅读文字的对比度至少 4.5:1. 大号文字可使用 3:1, 判定条件为交付字号至少 18pt, 或 14pt 粗体, Web 中对应 24 CSS 像素或约 18.67 CSS 像素粗体; 中日韩字体需满足规范中的等效尺寸. 用户放大不计入大号判定, 不确定时仍使用 4.5:1. 依据 [文字对比度及大号定义](https://www.w3.org/TR/WCAG22/#contrast-minimum).
+ 用于识别控件, 状态或理解图形的必要视觉部分, 与相邻颜色的对比度至少 3:1. 纯装饰分隔线不因此被要求加深. 依据 [非文字对比度](https://www.w3.org/TR/WCAG22/#non-text-contrast).
+ 键盘焦点必须可见, 且不能被作者创建的内容完全遮挡. 可使用清晰轮廓, 不依赖阴影或仅改变颜色. 依据 [可见焦点](https://www.w3.org/TR/WCAG22/#focus-visible) 与 [焦点不被遮挡](https://www.w3.org/TR/WCAG22/#focus-not-obscured-minimum).
+ 文字放大到 200% 后检查内容和功能是否丢失. 纵向滚动页面在 320 CSS 像素等效宽度下检查重排, 不让整页出现双向滚动; 需要二维表达的表格, 地图等可以局部滚动. 依据 [文字缩放](https://www.w3.org/TR/WCAG22/#resize-text) 与 [重排](https://www.w3.org/TR/WCAG22/#reflow).
+ 必要信息不用颜色单独表达. 表单提供文本标签和错误说明, 图表保留系列标签, 线型或符号等线索. 依据 [颜色的使用](https://www.w3.org/TR/WCAG22/#use-of-color).
+ 实现包含动效时, 响应平台的减少动态效果偏好. 无法运行交互或测量对比度时, 明确哪些检查尚未完成, 不从静态截图宣称完整可访问性合规.

## 静态版式适配

### 海报

+ 先确定成品尺寸, 方向, 阅读距离和输出用途. 缺少尺寸且影响实际制作时询问; 仅讨论构图时可以用相对比例, 不把构思稿称为可印刷成品.
+ 默认从 6 列模块网格起步, 密集内容可用 12 列. 外边距可从画幅短边的 5% 至 8% 起步, 结合裁切安全区调整.
+ 字号和线宽依据成品尺寸及观看距离选择, 按实际输出比例预览. 不把 Web 的 16px 正文, 1px 边框和固定断点搬到印刷版面.
+ 矩形图片裁切与文字容器对齐, 保留主题和必要标注. 用字号, 字重与位置确定阅读顺序, 不靠增添红色方块制造主焦点.

### 幻灯片

+ 先复用已有模板的画幅, 字体和页码规范. 没有指定画幅时默认 16:9, 从 6 列模块网格开始, 复杂图表页可用 12 列.
+ 无既定模板时, 标题可从 32 至 40pt, 正文从 20 至 24pt 起步, 注释通常不低于 14pt. 根据投影环境和观看距离提高字号, 不缩小关键数据标签以塞满页面.
+ 每页围绕一条主要信息组织层级, 多页可以有不同主焦点. 并列图表或比较数据保留一致尺度与图例, 不为追求非对称改变比较条件.
+ 图表复杂时调整分组或分页, 保留数据和必要解释. 在目标画幅预览, 检查文字溢出, 投影辨识度和灰阶输出.

### 文档与报告

+ 默认单栏阅读, 按语义组织标题和正文. 多栏用于明确适合比较或索引的内容, 不为使用网格而将连续正文切碎.
+ 未指定规格时, 可从 A4, 20mm 页边距, 11 至 12pt 正文和 1.5 倍行距起步. 标题通过少量字号和字重分级, 不套用网页首屏展示字号.
+ 用段落间距和细线分组, 表格保留列标题, 必要注释和一致单位. 检查分页, 标题与后续内容分离, 表格跨页和字体替换问题.
+ 按实际阅读用途检查输出: 打印稿按成品比例, 屏幕阅读稿按常用显示尺寸. 灰阶打印后, 强调与数据类别仍应可辨识.

## 下游提示词模板

仅在任务需要向图像模型, 界面生成工具或其他设计工具传递要求时使用. 先填入实际内容, 尺寸和必要规范, 删除不适用字段; 模板不能替代用户要求的实际制作. 下游工具需要英文时翻译已填好的提示词, 保留所有参数, 原文内容和例外条件.

```text
交付物: [媒介, 尺寸或视口, 输出格式]
目标与受众: [要传达的信息或要完成的操作]
内容: [实际文字, 数据, 图片及其优先级]
必须遵循的规范: [品牌, 模板, 现有设计系统; 没有则写无]

视觉方向: 用瑞士国际主义的网格, 字体和留白组织信息, 保持清晰, 理性, 克制.
信息层级: [当前页面或主要区域的主焦点和阅读顺序]
网格: [列数, 外边距, 列间距及跨列关系; 数字界面补充窄屏适配]
字体: [可用无衬线字体, 文字角色, 字号, 字重和行高]
几何: 默认方角, 主要容器共享对齐线, 必要时做文字与图标的光学校正.
配色: [中性色和一个可选强调色, 必要的状态或数据颜色及非颜色线索]
组件与素材: [按钮, 表格, 图表和图片的功能要求; 保留素材与数据含义]
例外: [需要偏离默认值的具体元素及原因; 没有则写无]

避免无信息作用的卡片, 图标, 渐变, 发光和装饰背景.
验收: [目标尺寸下的可读性, 内容完整性, 对齐和适用的交互检查]
```
