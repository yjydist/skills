# Spec Delta

## ADDED Requirements

### Requirement: 运行前提声明

skill-creator 自身和它产出的 skill 的 `SKILL.md` MUST 含 `## 前提条件` 一节, 列出该 skill 所有执行路径需要的运行时, 最低版本, 第三方依赖, 外部程序和认证, MUST NOT 只列当前请求用到的项. 每个条目 MUST 给出可执行的检查命令. 命令的脚本自身路径按执行时所在目录书写; 命令指向 skill 内部其他文件或依赖目录时, 路径 MUST 以 skill 目录为基准书写. 执行时脚本 MUST 按自身位置解析 skill 内部路径, MUST NOT 以当前工作目录作为 skill 内部路径的解析基准. 文档 MUST 给出在 skill 目录内与其他目录下的正确写法. 已安装版本低于要求时 MUST 按缺失处理. 本要求适用于 skill-creator 自身, 以及本流程新建或改进的 skill; 未改动的既有 skill 不因本规范更新而回溯强制补上该节, 但下次改进该 skill 时 MUST 补上.

#### Scenario: 新 skill 缺少前提条件

- **WHEN** 创建流程产出的 SKILL.md 没有 `## 前提条件`
- **THEN** 创建流程补上该节, 列出运行时, 版本, 依赖, 外部程序和认证, 否则不交付

#### Scenario: 依赖只被部分路径使用

- **WHEN** 某个外部程序只在部分执行路径需要
- **THEN** 仍列入 `## 前提条件`, 由检查统一处理, 不按当前请求裁剪

#### Scenario: 版本低于要求

- **WHEN** 外部程序存在但版本低于 `## 前提条件` 声明的最低版本
- **THEN** 按缺失处理, 进入阻断流程

#### Scenario: 路径解析

- **WHEN** 检查命令引用 skill 内的脚本或依赖目录
- **THEN** 命令的脚本自身路径按执行时所在目录书写, 指向 skill 内部其他文件或依赖目录的路径以 skill 目录为基准书写; 脚本按自身位置解析 skill 内部路径, 不依赖当前工作目录; 文档给出在 skill 目录内与其他目录下的正确写法

### Requirement: 前提检查与阻断

skill-creator 及其产出的 skill 在产出文件或执行脚本前 MUST 逐项检查 `## 前提条件`, 任一项不满足时 MUST 停止当前执行, MUST NOT 继续产出. 报告 MUST 含缺少项, 检测结果, 要求, 修复命令和影响. 随后 MUST 询问用户选择修复后继续, 授权降级或终止; 没有降级路径时 MUST 只提供修复和终止. MUST NOT 自动安装系统程序; 用户授权后 MAY 执行文档给出的安装命令. 用户未选择前 MUST NOT 继续.

#### Scenario: 缺少运行时或外部程序

- **WHEN** 检查发现运行时或外部程序缺失
- **THEN** 停止执行, 报告缺少项, 检测结果, 要求, 修复命令和影响, 并等待用户选择

#### Scenario: 用户授权降级

- **WHEN** 用户选择授权降级
- **THEN** 只在已定义降级路径内执行, 说明跳过的步骤和产物损失, 并记录在交付说明

#### Scenario: 没有降级路径

- **WHEN** 缺失项没有已定义的降级路径
- **THEN** 只提供修复后继续和终止两个选项, 不执行降级

#### Scenario: 用户未答复

- **WHEN** 报告后用户尚未选择
- **THEN** 保持停止, 不继续产出, 不默认选择降级

### Requirement: 运行环境与依赖自建

skill-creator 的脚本 MUST 通过 `## 前提条件` 声明的运行时执行. 第三方依赖 MUST 只按该节列出的清单安装; skill-creator MAY 在自身目录按需创建依赖目录并安装, MUST NOT 把 `package.json`, 锁文件或其他包管理器依赖清单提交到仓库. skill-creator MAY 在 `scripts/dependency-list.mjs` 维护代码内包名清单, 供运行时探测使用; 该文件只记录包名, 不参与安装, 不是包管理器依赖清单. 依赖目录存在但包缺失时 MAY 直接安装. 安装失败时 MUST 按前提缺失处理并报告原始错误. 依赖目录以外的路径 MUST NOT 被自动修改.

#### Scenario: 首次运行

- **WHEN** 依赖目录不存在
- **THEN** 创建依赖目录并安装 `## 前提条件` 列出的依赖, 然后重新检查

#### Scenario: 包缺失

- **WHEN** 依赖目录存在但缺少某个声明的包
- **THEN** 直接安装该依赖并重新检查

#### Scenario: 安装失败

- **WHEN** 安装命令失败
- **THEN** 按前提缺失处理, 报告安装命令的原始错误, 等待用户选择

#### Scenario: 不写入其他路径

- **WHEN** 需要安装依赖
- **THEN** 只写入 skill 目录内的依赖目录, 不修改系统或其他路径

## MODIFIED Requirements

### Requirement: 机械校验

skill-creator MUST 提供可重复执行的校验, 覆盖 frontmatter 可解析, name 与目录一致, 名称与描述约束, 可选字段, 正文非空, 本地链接目标存在且不含控制字符, 引用式链接定义存在. 校验 MUST 区分错误与警告: 标准违规为错误并以非零状态退出; 内容警告覆盖非标准字段, 未被 `SKILL.md` 直接引用或正文提到的 `scripts/` 与 `references/` 文件, 参考互引和正文过长; 可移植性警告覆盖目标存在的绝对路径, Windows 盘符或 UNC 路径, 越出 skill 目录, 路径大小写与磁盘不一致, 仅能按所在目录解析的链接. 未引用扫描 MUST NOT 检查顶层文件, `assets/`, 隐藏文件, `node_modules`, 依赖目录, `__pycache__` 目录与 `.pyc` 文件; `license` 指向目录内现有文件时 MUST 视为已引用. 警告默认只报告, 严格模式升级为错误. 无法运行校验时 MUST 按等价清单人工检查并说明. 链接检查与有界扫描的实现细则 (控制字符覆盖范围, 行内 HTML 与跨行标签, 同一行同一目标的去重, 扫描上限) 以 `skills/skill-creator/references/spec.md` 的 `校验脚本覆盖的检查` 一节为准.

#### Scenario: 名称与目录不一致

- **WHEN** SKILL.md 的 name 与父目录名不同
- **THEN** 报错误并以非零状态退出

#### Scenario: 非标准字段

- **WHEN** frontmatter 含标准外的字段
- **THEN** 报警告并列出字段名, 默认不影响退出状态, 严格模式下失败

#### Scenario: 引用不存在

- **WHEN** 正文或参考文件中的本地链接指向不存在的文件
- **THEN** 报错误并指出文件与行号

### Requirement: 交付说明

交付时 MUST 说明创建或修改的文件, 机械校验与验证结果, 以及未验证项. 前提检查结果 MUST 说明; 用户授权的降级 MUST 记录跳过的步骤, 未验证项和对产物的影响. 所在仓库对 skill 目录有额外规范时 MUST 按该规范补充, 未执行时 MUST 说明.

#### Scenario: 仓库要求使用文档

- **WHEN** 仓库规范要求每个 skill 提供使用文档和索引条目
- **THEN** 一并补齐, 并在交付说明中列出

#### Scenario: 脚本未运行

- **WHEN** 环境缺少运行校验脚本所需的条件
- **THEN** 说明原因, 并列出已人工核对的检查项

#### Scenario: 授权降级后交付

- **WHEN** 用户授权在缺少前提条件的情况下降级执行
- **THEN** 交付说明记录缺少项, 跳过的步骤, 未验证项和对产物的影响
