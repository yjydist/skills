# Spec Delta

## MODIFIED Requirements

### Requirement: 版式参数

模板 MUST 使用 A4 纸张宽度 21cm, 左右边距 1.9cm, 上下边距 2.54cm. 主表格列宽 MUST 为类别 14.3%, 内容 75.7%, 备注 10%. 信息行 MUST 使姓名与学号之间, 学号与日期之间的空白相等, 且姓名, 学号和日期 MUST 在同一行内显示, 不发生折行.

#### Scenario: 中文条目换行位置
- **WHEN** 以 12pt 字号渲染中文内容条目
- **THEN** 内容列每行容纳约 30 个全角字符, 备注列保留且不占用超过 10% 宽度

#### Scenario: 姓名不折行
- **WHEN** 姓名为默认值 `易靖远`
- **THEN** 姓名与学号, 日期在同一信息行内完整显示, 不发生折行

#### Scenario: 信息行等距
- **WHEN** 使用默认身份信息 `易靖远` 和 `26031210039G` 渲染
- **THEN** 姓名与学号之间, 学号与日期之间的空白相等
