# Design

## Context

见 `proposal.md` 的 Why. 与实现相关的现状:

+ 两个模板各自包含完整版式, `scripts/render.py` 只替换 `REPORT_DATA_START` 与 `REPORT_DATA_END` 之间的数据块. 交付的 `.typ` 必须能独立编译, 不能依赖 skill 安装路径或其他文件.
+ 自我评价当前用 `sym.ballot` / `sym.ballot.cross` 渲染. `Alimama FangYuanTi` 的字符表不含 `U+2610`, `U+2612`, `U+2713`, `U+2714`, 也不含 `U+3000`; 渲染时这些字符走字形级回退.
+ 最低版本 Typst 0.13: `curve` 自 0.13 引入, 与现状一致; `box.baseline` 是长期存在的参数.
+ 实测 `Alimama FangYuanTi` 的 `☐` 墨迹: 高约 `0.826em`, 底边在基线下约 `0.126em`.
+ 本机验证环境为 Typst 0.15.1, 300 DPI.

## Goals / Non-Goals

**Goals:**

+ 方框与勾完全由 Typst 矢量图形绘制, 不依赖任何字体字形.
+ 标记随字号等比缩放, 与文字的相对位置稳定.
+ 保持模板自包含, 不引入 import, 第三方包或外部图片.
+ 保持自评行的行内排版, 行高变化可忽略.

**Non-Goals:**

+ 不改变输入 JSON 格式, 校验规则, 产物命名或 `render.py`.
+ 不调整其他行的字体, 间距或表格结构.
+ 不为其他字符 (标点, 数字) 做字体替代方案.

## Decisions

### D1: 用 `box` + `curve` 绘制, 不使用符号字符

替代方案:

+ 打包一个包含 `☐`/`☒` 的字体: 增加字体文件与回退顺序复杂度, 且仍受字体版本影响.
+ 用 `sym.checkmark` 加方框: 勾仍是字符, 仍有回退.
+ 外部 SVG/PNG 图标: 破坏 `.typ` 独立编译, 且固定像素或需要额外缩放参数.

选择 `box` 与 `curve`, 两者都是 Typst 核心功能, 零外部依赖. 勾用百分比坐标, 相对方框自动缩放.

### D2: 方框参数以实测字形为基准

+ `width/height: 0.85em`, 对应原字形墨迹 `0.826em`.
+ `stroke: 0.5pt`, 与表格线一致.
+ `baseline: 0.11em`, 对应原字形底边在基线下约 `0.126em`.
+ `inset: 0pt`, 使勾的百分比坐标以整个方框为参照.

`box` 优于 `rect`: `rect` 没有 `baseline` 参数, 无法在行内精确控制方框相对文字基线的位置.

### D3: 勾用描边折线, 圆角端点

+ 端点: `(22%, 52%) -> (41%, 73%) -> (80%, 25%)`, 线宽 `0.10em`.
+ `cap: "round"`, `join: "round"` 避免小字号下出现尖角.
+ 替代填充多边形: 描边在 300 DPI 下已足够清晰, 不需要维护闭合轮廓的顶点顺序.

### D4: 显式 `h()` 间距替代全角空格

+ 方框与标签 `0.4em`, 三个选项之间 `1.2em`, 引导文字与第一个方框 `1em`.
+ `U+3000` 不在报告字体中, 使用它同样会产生回退; 显式长度不随字体变化.
+ 这些间距不提供换行点, 但自评行在当前列宽下有充足余量, 且中文本身可按字断行.

### D5: 两个模板各保留一份 helper

+ 两个模板本来就各自维护完整的 `evaluations` 定义和版式; 交付的 `.typ` 要求独立编译.
+ 抽公共 `import` 会让交付源文件依赖额外文件, 或在 `render.py` 中增加内联逻辑; 15 行重复的代价更低.
+ helper 放在数据块之后, 与现有局部函数 (`lines`, `head-cell` 等) 放在一起.

### D6: helper 参数不带默认值

Typst 中带默认值的参数只能按名传参. 若写成 `check-box(selected: false)`, 后续 `check-box(true)` 会报 `unexpected argument`. 因此定义为 `#let check-box(selected) = ...`, 由调用方显式传入比较结果.

## Risks / Trade-offs

+ [行高变化] 内联方框底部低于基线 `0.11em`, 自评行可能增高约 1.2pt (实测 300 DPI 下整图高度从 1754 变为 1759 像素). 页面高度自适应, 不影响交付形态. → 接受.
+ [比例硬编码] `0.85em` 与 `0.10em` 是视觉经验值, 依赖当前 12pt 正文. → 参数集中在 helper 中, 调整时只需改两处, 不扩散到行内容.
+ [颜色固定] 方框与勾使用黑色, 若将来修改正文颜色不会自动跟随. → 当前模板不设置自定义文字颜色, 可接受.
+ [验收依赖看图] 矢量形状无法用现有单元测试断言. → 任务中加入真实字体与回退字体两次渲染, 人工对照自评行.
+ [最低版本] `curve` 需要 Typst 0.13+, 与 skill 已声明的最低版本一致, 不新增版本约束.

## Migration Plan

两个模板同步修改, 无数据或接口迁移. 已交付的旧 `.typ` 仍可独立编译并保持原外观; 新渲染使用新标记.

回滚只需恢复模板中的 `evaluations` 定义和自我评价行, 不涉及脚本或文档结构.
